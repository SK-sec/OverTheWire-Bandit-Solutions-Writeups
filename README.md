\* \*\*Теория:\*\* ROT13 — частный случай шифра Цезаря. Команда `tr` (translate) заменяет одни символы на другие попарно. Мы указываем два диапазона (оригинальный алфавит и со смещением на 13 символов) для больших и маленьких букв.

\* \*\*Теория:\*\* Этот уровень тренирует работу с архиваторами (`gzip`, `bzip2`, `tar`) и утилитой `xxd` (создание и восстановление hex-дампов). Процесс требует циклического переименования и распаковки файла в зависимости от его текущего типа, который мы проверяем через `file`.

\* \*\*Команды (примерный пошаговый процесс):\*\*

&#x20; ```bash

&#x20; mkdir /tmp/my\_workspace \&\& cp data.txt /tmp/my\_workspace \&\& cd /tmp/my\_workspace

&#x20; xxd -r data.txt data\_bin          # Восстанавливаем из hex-дампа

&#x20; file data\_bin                     # Проверяем тип (допустим, gzip)

&#x20; mv data\_bin data\_bin.gz \&\& gunzip data\_bin.gz

&#x20; file data\_bin                     # Проверяем тип (допустим, bzip2)

&#x20; bzip2 -d data\_bin                 # Повторяем до тех пор, пока file не покажет ASCII text

\### 🔹 Level 32 ➔ Level 33

\* \*\*Цель:\*\* Сбежать из ограниченной командной оболочки (`UPPERCASE shell`), которая превращает все вводимые команды в заглавные буквы и выдает ошибку.

&#x20; # Произойдет вызов оригинального интерактивного shell (sh/bash) в обход фильтра.

&#x20; # Теперь мы в нормальном терминале:

&#x20; ```
